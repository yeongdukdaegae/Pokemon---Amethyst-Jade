# [저작권]

「Pokémon - AJ」는 비상업 팬게임입니다.
포켓몬스터(Pokémon)의 이름 · 캐릭터 · 설정 · 원작 그래픽과 음악의 저작권은 Nintendo · Creatures Inc. · GAME FREAK inc. · The Pokémon Company 에 있습니다.

아래는 이 게임에 들어 있는 에셋의 출처입니다. 가져온 에셋은 출처를, 이 게임을 위해 새로 만든 것은 "오리지널"로 적었습니다.
